1. Prerequisites

Verification of the following environment settings is required for a successful build:

  • Xcode 15.0+ Required
  • Deployment Target: iOS 16.1+
  • Swift 5.9+

2. API & Required Parameters

To initialize the SDK, you must have the following configuration parameters ready:

● Mobile Number: User mobile number (without +966).
● Country Code: Example: +966.
● Environment: Development or Production.
● Language: en or ar.
● Auth Code: Generated from the authentication API (expires in 5 minutes).
● Host ID: Your application identifier (e.g., "barq").
● User ID: Example: partner-abc-123.

A. Implementation Overview

Testing Credentials:
Use the following details for your sandbox environment:

phoneNumber: 554433220
countryCode: +966
authCode: Generate using the authentication API endpoint below

Note: You must call the auth code generation API before initializing the SDK. See Authentication Flow section for details.

Authentication Flow:

To enable user login via auth code (without OTP verification), follow the steps below:

  • Step 1: Generate Auth Code
    Call the ShoppingGate API from your backend to generate an auth code. This auth code is required for silent login without OTP verification.
    API Request
    curl -X 'POST' \
  'https://microservices.shoppinggate.app/users/users/sdk/generate-auth-code' \
  -H 'accept: */*' \
  -H 'Content-Type: application/json' \
  -d '{
  "host_id": "barq", // will be provided to you by Shoppingate
  "host_secret": "barq-xxxxx", // will be provided to you by Shoppingate
  "phone_number": "554433220", // Pass full phone number without country code dynamically from your app
  "phone_code": "+966",
  "device_id": "string"
}'
    API Response
    {
  "status": true,
  "message": "Auth code generated successfully",
  "data": {
    "auth_code": "5bd9f0fb-0c7a-4250-8b44-0b35e5a1a129",
    "expires_in": 300
  }
}
  • Step 2: Pass Auth Code to SDK
    Once you receive the auth_code from the API response, pass it to the SDK during initialization along with your host_id. The SDK will perform a silent login without requiring OTP verification.
    Swift Example
    let request = SgTravelNative.Request(
    phoneNumber: "554433220",
    countryCode: "+966",
    environment: "development",
    language: "en",
    auth_code: "5bd9f0fb-0c7a-4250-8b44-0b35e5a1a129", // From API response
    host_id: "barq" // Your host identifier
    partnerUserId: "partner-abc-123" //Your user ID
)

try SgTravelNative.shared.initialize(request: request)
    Note: The auth code expires in 300 seconds (5 minutes). Ensure you initialize the SDK within this timeframe.
Integration Steps:
1. Core Bridge (SgTravelNative.swift): Create a new Swift file named SgTravelNative.swift and paste the provided singleton code. This class manages the Flutter Engine lifecycle, handles Method Channel communication, and provides the navigation logic for presenting the SDK views.
2. UI Entry Points (ContentView.swift): Implement two primary entry points in your UI: one for the Booking Flow (searching and booking) and one for Booking History/Orders. Use the initialize method with your specific credentials before calling the respective "open" methods.
3. Native Payment (PaymentView.swift): The payment UI is developed on the client side (native). When a user triggers a payment action, your native code must invoke the invokePaymentInitiateMethod via the bridge.

B. Code Implementation

SgTravelNative.swift
import UIKit
import SwiftUI
import Flutter
import FlutterPluginRegistrant

final class SgTravelNative: NSObject {
    static let shared = SgTravelNative()
    
    class Request {
        let phoneNumber: String = "554433220"
        let countryCode: String = "+966"
        let environment: String = "development"
        let language: String = "en"
        var authCode: String = ""
        let host_id: String = "barq"
        let partnerUserId: String = "1"
    }

    private struct ChannelCall {
        let method: String
        let arguments: Any?
    }

    private struct PaymentPayload {
        let amount: Double
        let orderId: String?
        let requestPaymentType: String?
    }

    private enum NativeError: LocalizedError {
        case missingInitialData
        case invalidArgument
        case invalidEnvironment
        case missingPresenter

        var errorDescription: String? {
            switch self {
            case .missingInitialData:
                return "Initialize request not found. Call SgTravelNative.initialize first."
            case .invalidArgument:
                return "Required keys: phoneNumber, countryCode, environment, language, authCode"
            case .invalidEnvironment:
                return "Use environment: development or production"
            case .missingPresenter:
                return "Unable to find a presenter for the Flutter host view controller."
            }
        }
    }

    private let channelName = "shoppingate_travel_sdk/channel"
    private let engineName = "sg_travel_sdk_engine"

    private let methodInitialize = "initialize"
    private let methodOpenBookingFlow = "openBookingFlow"
    private let methodOpenOrderFlow = "openOrderFlow"
    private let methodHostReady = "hostReady"
    private let methodSetUserData = "setUserData"
    private let methodCloseSDK = "closeSDK"
    private let methodPaymentInitiation = "invokePaymentInitiation"
    private let methodContinueToPayment = "continueToPayment"

    private let keyPhone = "phoneNumber"
    private let keyCountry = "countryCode"
    private let keyEnvironment = "environment"
    private let keyLanguage = "language"
    private let keyAuthCode = "authCode"
    private let keyPartnerUserId = "partnerUserId"

    // Changed to Optional so we can truly "destroy" and "recreate" it
    private var engine: FlutterEngine?
    private var isInitialized = false
    private var isFlutterReady = false
    private var latestData: [String: Any] = [:]
    private var pendingCalls: [ChannelCall] = []
    private var methodChannel: FlutterMethodChannel?

    private override init() {
        super.init()
    }

    func initialize(request: Request) throws {
        let normalized = try normalize(request: request)
        
        latestData = normalized
        isInitialized = true

        ensureEngineStarted()
        // Always queue initialization when calling initialize explicitly
        dispatchOrQueue(method: methodInitialize, arguments: normalized)
    }

    func openBooking() throws {
        try ensureReadyToOpen()
        try presentHost()
        dispatchOrQueue(method: methodOpenBookingFlow, arguments: nil)
    }

    func openOrder() throws {
        
        try ensureReadyToOpen()
        try presentHost()
        dispatchOrQueue(method: methodOpenOrderFlow, arguments: nil)
    }
    
    /// Internal helper to check if we need to restart the engine and re-init
    private func ensureReadyToOpen() throws {
        guard isInitialized else { throw NativeError.missingInitialData }
        
        // If engine was destroyed, we restart it
        if engine == nil {
            ensureEngineStarted()
            // Re-queue the initialization using stored data before opening the flow
            dispatchOrQueue(method: methodInitialize, arguments: latestData)
        }
    }

    func destroy() {
        methodChannel?.setMethodCallHandler(nil)
        methodChannel = nil
        isFlutterReady = false
        pendingCalls.removeAll()

        if let engine = engine {
            engine.destroyContext()
        }
        engine = nil
    }

    private func ensureEngineStarted() {
        guard engine == nil else { return }
        let newEngine = FlutterEngine(name: engineName)
        newEngine.run(withEntrypoint: "travelSdkHostEntryPoint")
        GeneratedPluginRegistrant.register(with: newEngine)
        attachChannel(to: newEngine)
        self.engine = newEngine
    }

    private func attachChannel(to engine: FlutterEngine) {
        let channel = FlutterMethodChannel(name: channelName, binaryMessenger: engine.binaryMessenger)
        methodChannel = channel
        isFlutterReady = false

        channel.setMethodCallHandler { [weak self] call, result in
            self?.handleMethodCall(call, result: result)
        }
    }

    private func handleMethodCall(_ call: FlutterMethodCall, result: @escaping FlutterResult) {
        switch call.method {
        case methodHostReady:
            isFlutterReady = true
            result(nil)
            flushPendingCallsIfReady()

        case methodSetUserData:
            guard let raw = call.arguments as? [AnyHashable: Any] else {
                result(FlutterError(code: "INVALID_ARGUMENT", message: NativeError.invalidArgument.errorDescription, details: nil))
                return
            }

            do {
                latestData = try normalize(payload: raw)
                result(nil)
            } catch {
                result(FlutterError(code: "INVALID_ARGUMENT", message: error.localizedDescription, details: nil))
            }

        case methodCloseSDK:
            result(nil)
            dismissHost() // Use the unified dismiss logic
            
        case methodContinueToPayment:
            let payload = parsePaymentPayload(call.arguments)
            print("Received payment data: amount=\(payload.amount), orderId=\(payload.orderId ?? "nil")")
            DispatchQueue.main.async {
                self.presentPaymentScreen(payload: payload)
            }
            result(nil)
        default:
            result(FlutterMethodNotImplemented)
        }
    }

    private func dispatchOrQueue(method: String, arguments: Any?) {
        guard let methodChannel = methodChannel, isFlutterReady else {
            pendingCalls.append(ChannelCall(method: method, arguments: arguments))
            return
        }

        methodChannel.invokeMethod(method, arguments: arguments)
    }

    private func flushPendingCallsIfReady() {
        guard let methodChannel = methodChannel, isFlutterReady, !pendingCalls.isEmpty else { return }

        let queuedCalls = pendingCalls
        pendingCalls.removeAll()

        queuedCalls.forEach { call in
            methodChannel.invokeMethod(call.method, arguments: call.arguments)
        }
    }

    private func presentHost() throws {
        guard let presenter = topViewController() else {
            throw NativeError.missingPresenter
        }

        if presenter is FlutterViewController || presenter.navigationController?.viewControllers.last is FlutterViewController {
            return
        }

        guard let engine = engine else { return }
        let flutterViewController = FlutterViewController(engine: engine, nibName: nil, bundle: nil)
        flutterViewController.title = "Travel SDK"
        flutterViewController.navigationItem.leftBarButtonItem = UIBarButtonItem(
            barButtonSystemItem: .close,
            target: self,
            action: #selector(dismissHost)
        )

        let navigationController = UINavigationController(rootViewController: flutterViewController)
        navigationController.modalPresentationStyle = .fullScreen
        presenter.present(navigationController, animated: true)
    }

    @objc
    private func dismissHost() {
        topViewController()?.dismiss(animated: true) { [weak self] in
            // When the UI is hidden, destroy all connections and memory
            self?.destroy()
        }
    }

    private func topViewController(
        from rootViewController: UIViewController? = UIApplication.shared
            .connectedScenes
            .compactMap { $0 as? UIWindowScene }
            .flatMap { $0.windows }
            .first(where: \ .isKeyWindow)?.rootViewController
    ) -> UIViewController? {
        if let navigationController = rootViewController as? UINavigationController {
            return topViewController(from: navigationController.visibleViewController)
        }

        if let tabBarController = rootViewController as? UITabBarController,
           let selectedViewController = tabBarController.selectedViewController {
            return topViewController(from: selectedViewController)
        }

        if let presentedViewController = rootViewController?.presentedViewController {
            return topViewController(from: presentedViewController)
        }

        return rootViewController
    }

    private func normalize(request: Request) throws -> [String: Any] {
        try normalize(payload: [
            keyPhone: request.phoneNumber,
            keyCountry: request.countryCode,
            keyEnvironment: request.environment,
            keyLanguage: request.language,
            keyAuthCode: request.authCode,
            keyPartnerUserId: request.partnerUserId
            
        ])
    }

    private func normalize(payload: [AnyHashable: Any]) throws -> [String: Any] {
        let phoneNumber = try readRequiredString(payload, key: keyPhone)
        let countryCode = try readRequiredString(payload, key: keyCountry)
        let environment = try readRequiredString(payload, key: keyEnvironment)
        let language = try readRequiredString(payload, key: keyLanguage)
        let authCode = try readRequiredString(payload, key: keyAuthCode)
        let partnerUserId = try readRequiredString(payload, key: keyPartnerUserId)
        
        guard environment == "development" || environment == "production" else {
            throw NativeError.invalidEnvironment
        }

        return [
            keyPhone: phoneNumber,
            keyCountry: countryCode,
            keyEnvironment: environment,
            keyLanguage: language,
            keyAuthCode: authCode,
            keyPartnerUserId: partnerUserId
        ]
    }

    private func readRequiredString(_ payload: [AnyHashable: Any], key: String) throws -> String {
        let value = (payload[key] as? String)?.trimmingCharacters(in: .whitespacesAndNewlines) ?? ""
        guard !value.isEmpty else {
            throw NativeError.invalidArgument
        }
        return value
    }

    func invokePaymentInitiateMethod(arg: String) {
        guard let methodChannel = methodChannel, isFlutterReady else { return }
        methodChannel.invokeMethod(methodPaymentInitiation, arguments: arg)
    }
    
    private func presentPaymentScreen(payload: PaymentPayload) {
        guard let presenter = topViewController() else { return }
        let paymentView = PaymentView(
            amount: payload.amount,
            orderId: payload.orderId,
            requestPaymentType: payload.requestPaymentType
        )
        let hostingController = UIHostingController(rootView: paymentView)
        hostingController.modalPresentationStyle = .formSheet
        if let sheet = hostingController.sheetPresentationController {
            sheet.detents = [.custom(resolver: { _ in 320 })]
            sheet.prefersGrabberVisible = true
            sheet.preferredCornerRadius = 16
            sheet.largestUndimmedDetentIdentifier = .medium
        }
        if #available(iOS 13.0, *) {
            hostingController.isModalInPresentation = true // disables drag-to-dismiss
        }
        presenter.present(hostingController, animated: true)
    }

    private func parsePaymentPayload(_ arguments: Any?) -> PaymentPayload {
        if let mapPayload = arguments as? [String: Any] {
            let amount = (mapPayload["total_amount"] as? NSNumber)?.doubleValue ?? 0.0
            let orderId = mapPayload["order_id"].map { String(describing: $0) }
            let requestPaymentType = mapPayload["request_payment_type"] as? String
            return PaymentPayload(
                amount: amount,
                orderId: orderId,
                requestPaymentType: requestPaymentType
            )
        }

        if let amount = (arguments as? NSNumber)?.doubleValue {
            return PaymentPayload(amount: amount, orderId: nil, requestPaymentType: nil)
        }

        return PaymentPayload(amount: 0.0, orderId: nil, requestPaymentType: nil)
    }
}
ContentView.swift
import SwiftUI

struct ContentView: View {
    @State private var statusMessage = "SDK not initialized"

    private enum SdkFlowType {
        case booking
        case order
    }
    
    private let request = SgTravelNative.Request()

    var body: some View {
        VStack(alignment: .leading, spacing: 20) {
            VStack(alignment: .leading, spacing: 8) {
                Text("Shopping Gate Travel SDK")
                    .font(.title2)
                    .fontWeight(.semibold)
                Text(statusMessage)
                    .font(.subheadline)
                    .foregroundStyle(.secondary)
            }

            Button("Open Booking Flow") {
                Task {
                    await generateAuthTokenForSDK(openFlow: .booking)
                }
            }
            .buttonStyle(.bordered)

            Button("Open Order Flow") {
                Task {
                    await generateAuthTokenForSDK(openFlow: .order)
                }
            }
            .buttonStyle(.bordered)

            Spacer()
        }
        .padding()
        .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .topLeading)
    }

    private func initializeSdk(_ authCode: String) {
        request.authCode = authCode
        
        do {
            try SgTravelNative.shared.initialize(request: request)
            statusMessage = "You can open booking or orders now."
        } catch {
            statusMessage = error.localizedDescription
        }
    }
    
    private func generateAuthTokenForSDK(openFlow: SdkFlowType) async {
        do {
            let body: [String: Any] = await [
                "host_id": "barq",
                "host_secret": "barq-secret",
                "phone_number": request.phoneNumber,
                "phone_code": request.countryCode,
                "device_id": getDeviceId()
            ]

            let result = try await AuthRepository.shared.generateAuthTokenForSDK(body: body)

            if result.status {
                if let authCode = result.data["auth_code"] as? String {
                    // Await SDK initialization
                    await withCheckedContinuation { continuation in
                        DispatchQueue.main.async {
                            self.initializeSdk(authCode)
                            continuation.resume()
                        }
                    }
                    
                    do {
                        print("native, generateAuthTokenForSDK")
                        switch openFlow {
                        case .booking:
                            try SgTravelNative.shared.openBooking()
                        case .order:
                            try SgTravelNative.shared.openOrder()
                        }
                    } catch {
                        statusMessage = error.localizedDescription
                    }
                } else {
                    setError("Auth code missing")
                }
            } else {
                setError(result.message ?? "Unknown error")
            }
        } catch {
            setError(error.localizedDescription)
        }
    }
    
    private func getDeviceId() async -> String {
        return UIDevice.current.identifierForVendor?.uuidString ?? "simulator"
    }
    
    private func setError(_ message: String) {
        statusMessage = "Error: \(message)"
    }
}

struct AuthResponse {
    let status: Bool
    let data: [String: Any]
    let message: String?
}

class AuthRepository {
    static let shared = AuthRepository()
    let apiURL = "https://microservices.shoppinggate.app/users/users/sdk/generate-auth-code"
    
    private init() {}
    
    func generateAuthTokenForSDK(body: [String: Any]) async throws -> AuthResponse {
        
        guard let url = URL(string: apiURL) else {
            throw URLError(.badURL)
        }
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.httpBody = try JSONSerialization.data(withJSONObject: body)
        
        let (data, _) = try await URLSession.shared.data(for: request)
        let json = try JSONSerialization.jsonObject(with: data) as? [String: Any] ?? [:]
        let status = json["status"] as? Bool ?? false
        let message = json["message"] as? String
        let responseData = json["data"] as? [String: Any] ?? [:]
        return AuthResponse(status: status, data: responseData, message: message)
    }
}
PaymentView.swift
import SwiftUI

struct PaymentView: View {
    @State var isPaymentInitiated: Bool = false
    let amount: Double
    let orderId: String?
    let requestPaymentType: String?
    @Environment(\.presentationMode) var presentationMode
    
    var body: some View {
        VStack(spacing: 0) {
            HStack {
                Text("Payment Method")
                    .font(.headline)
                    .padding(.leading, 26)
                Spacer()
                Button(action: {
                    presentationMode.wrappedValue.dismiss()
                }) {
                    Image(systemName: "xmark.circle.fill")
                        .resizable()
                        .frame(width: 28, height: 28)
                        .foregroundColor(.secondary)
                        .padding(16)
                }
                .accessibilityLabel("Close")
            }
            .padding(.top, 8)
            walletView
                .padding(.top, 20)
            Spacer()
            footerView
        }
        .background(Color(.systemBackground))
    }

    private var walletView: some View {
        HStack(alignment: .center, spacing: 16) {
            ZStack {
                RoundedRectangle(cornerRadius: 8)
                    .stroke(Color("themeColor"), lineWidth: 1)
                    .frame(width: 32, height: 32)
                Image("ic_wallet")
                    .resizable()
                    .scaledToFit()
                    .frame(width: 18, height: 18)
            }
            VStack(alignment: .leading, spacing: 2) {
                Text("Barq Wallet")
                    .font(.headline)
            }
            Spacer()
            Image("ic_selected")
                .resizable()
                .frame(width: 22, height: 22)
        }
        .padding(.horizontal, 16)
        .padding(.vertical, 10)
        .background(
            RoundedRectangle(cornerRadius: 12)
                .stroke(Color("themeColor").opacity(0.5), lineWidth: 1)
        )
        .padding(.horizontal, 16)
        .padding(.top, 4)
    }

    private var footerView: some View {
        VStack(spacing: 0) {
            Divider()
            HStack {
                Text("Amount: \(String(format: "%.2f", amount))")
                    .font(.headline)
                Spacer()
                Button(action: {
                    isPaymentInitiated = true
                    let transactionId = buildTransactionId(orderId: orderId)
                    SgTravelNative.shared.invokePaymentInitiateMethod(arg: transactionId)
                    // Auto-close native payment sheet after sending callback.
                    DispatchQueue.main.asyncAfter(deadline: .now() + 0.3) {
                        presentationMode.wrappedValue.dismiss()
                    }
                }) {
                    Text("Pay Now")
                        .padding(.horizontal, 24)
                        .padding(.vertical, 10)
                        .background(Color("themeColor"))
                        .foregroundColor(.white)
                        .cornerRadius(8)
                }
                .disabled(isPaymentInitiated)
            }
            .padding([.horizontal, .top], 16)
            .padding(.bottom, 24)
        }
    }

    private func buildTransactionId(orderId: String?) -> String {
        let timestamp = Int(Date().timeIntervalSince1970 * 1000)
        if let orderId = orderId, !orderId.isEmpty {
            return "TXN_\(orderId)_\(timestamp)"
        }
        return "TXN_\(timestamp)"
    }
